User study on performance of developers using *copilots* or *coding agents*.

- tasks including fixing issues, adding features, and conducting deep research in repositories
- agents improve task correctness and reduce effort (time writing prompts)
- human better understanding copilot output
  - "*sometimes copilot will provide bad code*" but bad code helps human understand the problem better
  - while agents are still significantly perferred (can complete task could not have been completed without them)
- human effort in agentic workflows is largely used to oversee in debugging
- insights:
  - agent behavior should be transparent
  - need better control of agents (what to do, when to stop)
  - how to avoid "*I'm just kind of sitting there*" scenarios where human is not actively engaged in the task -> multitasking?
